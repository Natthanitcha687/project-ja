# Warranty Platform — User Onboarding & Quick Guide

เวอร์ชัน: 1.0

## บทนำสั้น ๆ
เอกสารนี้รวบรวม "ไกด์ไลน์การใช้งานครั้งแรก (User Onboarding)" และ "คู่มือแนะนำการใช้งาน (Quick Guide)" สำหรับผู้ใช้ 2 ประเภทบน Warranty Platform: ร้านค้า (Shop) และ ผู้ซื้อสินค้า (Customer). เนื้อหาเขียนในโทนกระชับ เข้าใจง่าย และพร้อมนำไปใช้กับ UI ได้ทันที.

## Welcome Message

### ร้านค้า (Shop)
- "ยินดีต้อนรับสู่ Warranty Platform 🎉 — พร้อมช่วยจัดการรับประกันและเคลมในที่เดียว ให้คุณเริ่มได้ทันที"

จุดประสงค์: กระตุ้นความมั่นใจ และให้ผู้ใช้รู้ว่าพร้อมเริ่มงานได้อย่างรวดเร็ว

### ลูกค้า (Customer)
- "ยินดีต้อนรับ! ตรวจสอบสถานะรับประกันและเอกสารดิจิทัลของคุณได้ที่นี่ 🔍"

จุดประสงค์: สื่อประโยชน์หลักทันที — ตรวจสอบสถานะและเอกสารได้ง่าย

## Empty State — Dashboard (ร้านค้า)

**หัวข้อ:** ยังไม่มีใบรับประกันแรกของคุณ

**ข้อความแนะนำ:**
สร้างใบรับประกันเพื่อเริ่มติดตามการเคลมและรับการแจ้งเตือนอัตโนมัติ — กระบวนการรวดเร็วและเก็บข้อมูลลูกค้าได้ครบ

**ขั้นตอนสั้น ๆ:**
1. กดสร้างใบรับประกัน
2. กรอกข้อมูลสินค้าและลูกค้า
3. บันทึกและส่งลิงก์ให้ลูกค้า

**ปุ่ม CTA:**
- Primary: สร้างใบรับประกันใหม่
- Secondary: นำเข้าลูกค้า / ดูตัวอย่าง

**UX note:** ใส่ไอคอน "+" ในปุ่มหลัก และ tooltip สั้นใต้ปุ่มว่า “ใช้เวลา < 2 นาที”

## Step-by-step Tooltip (ป๊อปอัปแนะนำเมนู) — สำหรับร้านค้า
คำแนะนำแต่ละ tooltip ต้องสั้น กระชับ และมีปุ่มชัดเจนให้ผู้ใช้ทำตามหรือข้ามได้

1) สร้างใบรับประกัน
- ข้อความ: "เริ่มที่นี่เพื่อสร้างบัตรรับประกันใหม่ — ใส่รหัสสินค้าและข้อมูลลูกค้า แล้วบันทึกเพื่อส่งลิงก์ให้ลูกค้าได้ทันที"
- ปุ่ม: สร้างตอนนี้ / ข้าม

2) ลูกค้า
- ข้อความ: "ดูหรือแก้ไขข้อมูลลูกค้า ค้นหาด้วยอีเมลหรือเบอร์โทรเพื่อดูใบรับประกันที่เกี่ยวข้อง"
- ปุ่ม: เปิดรายชื่อลูกค้า / ข้าม

3) เคลม / คำร้อง
- ข้อความ: "ติดตามสถานะคำร้อง รับ หรืออนุมัติคำร้อง ดูประวัติการซ่อมและค่าใช้จ่าย"
- ปุ่ม: ดูคำร้องที่รอดำเนินการ / ข้าม

4) แจ้งเตือน & รายงาน
- ข้อความ: "ตั้งเตือนก่อนหมดอายุ และดูสถิติการเคลมเพื่อปรับปรุงบริการ"
- ปุ่ม: ตั้งค่าการแจ้งเตือน / ข้าม

## Color Coding Guide — ฝั่งลูกค้า (สรุปสั้น ๆ)
- สีเขียว (Green) — คุ้มครอง: การรับประกันยังทำงานตามปกติ ✅
- สีเหลือง (Yellow) — ใกล้หมดอายุ: เหลือเวลาไม่มาก ควรตรวจสอบเงื่อนไข 🔔
- สีแดง (Red) — หมดอายุ: การรับประกันสิ้นสุดแล้ว ❗

**Accessibility:** ให้เพิ่มไอคอนหรือข้อความเสริม (เช่น "Active / Expiring / Expired") สำหรับผู้ที่มองเห็นสีได้ยาก

## แนวปฏิบัติการนำไปใช้ (Implementation notes)
- แต่ละ tooltip ให้มีปุ่ม “ข้าม” และตัวเลือก “แสดงอีกครั้ง” ในเมนูช่วยเหลือ
- เก็บสถานะการแสดง tooltip ต่อผู้ใช้ (localStorage หรือ user setting) เพื่อไม่ให้รบกวนบ่อย
- Empty state: เพิ่มลิงก์ไปยังหน้าสร้างใบรับประกัน และวิดีโอสั้น 30–60 วินาที (ถ้ามี) เพื่อช่วยการเริ่มต้น
- สำหรับสีสถานะ: ให้ใช้ทั้งสีและ label text เพื่อรองรับ accessibility

## คำถามที่อาจเกิดขึ้น (FAQ สั้น)
- Q: จะสร้างใบรับประกันได้อย่างไร?  
  A: กด "สร้างใบรับประกันใหม่" จาก Dashboard แล้วกรอกข้อมูลสินค้าและลูกค้า
- Q: ลูกค้าได้รับใบรับประกันอย่างไร?  
  A: ระบบจะส่งลิงก์ผ่านอีเมลหรือ SMS เมื่อบันทึกบัตรรับประกัน
