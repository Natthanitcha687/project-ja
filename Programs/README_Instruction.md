# คู่มือการใช้งานโปรแกรม (Programs Folder)

โฟลเดอร์นี้รวบรวมไฟล์ที่พร้อมใช้งานสำหรับโครงการ **SMA Warranty Platform** เพื่อให้กรรมการสามารถตรวจสอบและรันโปรแกรมได้โดยสะดวก

---

## 📁 โครงสร้างโฟลเดอร์
1.  **Backend_Setup**: โค้ดส่วนหลังบ้าน (Node.js + Prisma) ที่พร้อมรัน
2.  **Frontend_Build**: ไฟล์ Production Build ของหน้าเว็บฝั่งลูกค้า (พร้อมใช้งานแล้ว)
3.  **Admin_Build**: ไฟล์ Production Build ของหน้าเว็บฝั่งผู้ดูแลระบบ (พร้อมใช้งานแล้ว)
4.  **database_backup.sql**: ไฟล์สำหรับ Import ฐานข้อมูลไปยัง PostgreSQL
5.  **Go_to_Website.url**: ทางลัดเข้าสู่เว็บไซต์เวอร์ชันออนไลน์ (บน Render)

---

## 🛠️ สิ่งที่ต้องมีก่อนรัน (Prerequisites)
เพื่อให้โปรแกรมทำงานได้สมบูรณ์ กรุณาติดตั้งซอฟต์แวร์ดังต่อไปนี้:
*   **Node.js** (เวอร์ชัน 18 ขึ้นไป): [ดาวน์โหลดที่นี่](https://nodejs.org/)
*   **PostgreSQL**: [ดาวน์โหลดที่นี่](https://www.postgresql.org/download/)

---

## 🚀 วิธีการเริ่มทำงาน (Quick Start)

### 1. ตั้งค่าฐานข้อมูล (Database Setup)
1.  เปิดโปรแกรม **pgAdmin** หรือเครื่องมือจัดการ PostgreSQL อื่นๆ
2.  สร้างฐานข้อมูลใหม่ชื่อ `Sma_warranty_dev`
3.  รันคำสั่ง SQL จากไฟล์ `database_backup.sql` เพื่อสร้าง Table ต่างๆ

### 2. รันโปรแกรมด้วยไฟล์อัตโนมัติ (Automation Script)
1.  ดับเบิลคลิกที่ไฟล์ **`Start_Server.bat`**
2.  โปรแกรมจะทำการติดตั้ง dependencies (หากยังไม่มี) และเริ่มทำงาน
3.  หน้าเว็บจะถูกเปิดขึ้นโดยอัตโนมัติที่:
    *   **ลูกค้า:** [http://localhost:5173](http://localhost:5173)
    *   **ผู้ดูแล:** [http://localhost:5174](http://localhost:5174)

---

## 📝 หมายเหตุ
*   ไฟล์ `.env` ในโฟลเดอร์ `Backend_Setup` มีการตั้งค่าพื้นฐานไว้แล้ว หากท่านเปลี่ยนรหัสผ่าน PostgreSQL กรุณาแก้ไขที่ค่า `DATABASE_URL` ในไฟล์นั้นก่อนเริ่มรัน
*   **สำคัญ:** กรุณาตรวจสอบและตั้งค่าไฟล์ `.env` ให้ถูกต้องเผื่อการทดสอบในเครื่องของท่าน (ดูตัวอย่างและคำอธิบายค่าต่างๆ ได้จากไฟล์ **`.env.example`**) โดยเฉพาะรหัสผ่านฐานข้อมูลและข้อมูล Gmail App Password
*   หากต้องการดูเว็บไซต์เวอร์ชันออนไลน์ (ไม่ต้องรันเอง) สามารถเข้าได้ที่ลิงก์ในไฟล์ Go_to_Website.url
